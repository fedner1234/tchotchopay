**Title:**
Flutter + Firebase Developer Needed — Fintech Remittance App (Haiti / USDC / Stripe)

---

**Job Description:**

We are building **Tchotcho Pay** — a fintech mobile app for the Haitian diaspora that combines money transfer, USDC digital wallet on Base blockchain, Visa Debit card, and a Haitian marketplace. Think Cash App meets MonCash, built for Haitians in the US, Canada, and France sending money home.

The website is already live at **tchotchopay.com**. We have full design specs, a detailed developer handoff document, and a FlutterFlow project already started. We need an experienced Flutter/Firebase developer to build the complete iOS and Android app.

---

**What You'll Build:**

A Flutter app with 25 screens across 5 tabs:
- **Auth flow** — Sign up, phone OTP, KYC identity verification
- **Home/Wallet** — USDC balance card, transaction history, add funds
- **Send Money** — Amount entry, recipient search, review, success
- **Visa Card** — 3D flip animation, virtual card, freeze/unfreeze
- **Marketplace** — Mobile top-up, bill pay, QR merchant payments
- **Profile** — KYC status, security settings, referral program

---

**Tech Stack Required:**

- Flutter (Dart) — iOS and Android
- Firebase (Auth, Firestore, Storage, Cloud Functions)
- Stripe SDK + Stripe Issuing (Visa card)
- Plaid Link SDK (bank verification)
- Bridge API (USDC on Base blockchain)
- Unit or Synctera API (banking/KYC)
- Reloadly API (Haiti mobile top-ups)
- OneSignal or Firebase FCM (push notifications)

## HOW TO SCREEN CANDIDATES

When reviewing applications, look for these green flags:

**Green Flags ✅**
- Shows you App Store / Play Store links to real published apps
- Has built a payment or fintech app before
- Mentions Stripe by product name (not just "Stripe")
- Asks intelligent questions about the spec
- Provides a detailed timeline breakdown
- Starts with "TCP2026" (shows they read the posting)

**Red Flags ❌**
- No portfolio or only design mockups
- Says they can build it in 2-3 weeks (too fast, means corners cut)
- Can't explain how Firebase Cloud Functions work
- Asks for 50%+ upfront before any milestone
- No reviews or feedback on their profile
- Copy-paste generic proposal

## RECOMMENDED PAYMENT STRUCTURE

Split the project into milestones — never pay all upfront:

| Milestone | Payment | When |
|-----------|---------|------|
| 1 — Auth flow complete (signup, login, KYC) | 20% | End of week 3 |
| 2 — Wallet + Send Money complete | 20% | End of week 6 |
| 3 — Card + Marketplace complete | 20% | End of week 9 |
| 4 — All APIs connected + tested | 20% | End of week 11 |
| 5 — App Store + Play Store approved | 20% | After approval |

**Total: 100% paid over 5 milestones**

This protects you — if the developer disappears or delivers bad work, you only lose what you've paid up to that point.
