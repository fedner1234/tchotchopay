## CONNECTING NETLIFY FORMS → ZOHO CAMPAIGNS

Netlify and Zoho Campaigns don't connect natively. Two options:

**Option A — Zapier (easiest, free tier available)**
1. Go to zapier.com
2. Create a Zap: Trigger = "New Netlify Form Submission" → Action = "Add Subscriber to Zoho Campaigns"
3. Map the email field → done. Every new waitlist signup auto-adds to Zoho.

**Option B — Manual CSV**
1. In Netlify → Forms → waitlist → Export submissions as CSV
2. In Zoho Campaigns → Contacts → Import → upload the CSV
3. Do this weekly until you set up Zapier

Option A is strongly recommended — set it up once and it runs forever.
