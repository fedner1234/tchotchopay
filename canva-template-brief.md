## TEMPLATE 1 — INSTAGRAM SQUARE (1080 × 1080 px)
*Use this for every Instagram and WhatsApp post.*

### Layout structure

```
┌─────────────────────────────────────┐
│  [Logo top-left]    [Badge top-right]│  ← 60px from edges
│                                      │
│                                      │
│   [HEADLINE — 2 lines max]           │  ← center, 72px font
│                                      │
│   [Body text — 2–3 lines]            │  ← center, 36px font
│                                      │
│   [Stat pills row]                   │  ← 3 rounded pills
│                                      │
│  [tchotchopay.com]    [Flag 🇭🇹]     │  ← bottom bar
└─────────────────────────────────────┘
```

### Step-by-step build in Canva

1. **New design** → Custom size → 1080 × 1080 px
2. **Background**: Rectangle, full canvas, fill `#020B2D`
3. **Subtle grid overlay** (optional): Add a second rectangle, full canvas, fill `#0A1F6E`, opacity 20%, add a dot pattern texture from Canva's Elements > Grids
4. **Logo**: Upload your Tchotcho Pay logo PNG (white version), place top-left, width ~200px, 60px from edges
5. **Badge** (top-right): Rounded rectangle, fill `#00C896` (green for "Live") or `#F7B731` (gold for "Coming Soon"), 24px corner radius. White text, Inter Medium, 28px — e.g. "DISPONIB KOUNYE A"
6. **Headline**: Poppins Bold, 72–80px, color `#F0F6FF`. Center-aligned. Max 2 lines. Example: "Voye Lajan\nAyiti an 60 Sègonn"
7. **Accent line**: Thin horizontal line under headline, color `#00AEEF`, width 200px, height 4px, centered
8. **Body text**: Inter Regular, 36px, color `#7FD4F7`. Center-aligned. 2–3 lines max
9. **Stat pills** (3 pills in a row):
   - Each pill: Rounded rectangle, fill `#0A1F6E`, border 2px `#00AEEF`, corner radius 40px, width ~280px, height 72px
   - Text inside: Inter Medium, 30px, white — e.g. "≤ 3% Frè", "60 Sègonn", "24/7"
   - Space evenly, centered horizontally
10. **Bottom bar**: Rectangle, full width, height 80px, fill `#0A1F6E`, pinned to bottom. White text left: `tchotchopay.com` (Inter Medium, 30px, `#00AEEF`). Right: 🇭🇹 emoji, 48px

### Swap zone — what changes per post
Only these elements change between posts:
- Headline text
- Body text
- Badge text/color
- Stat pills content

Everything else stays locked.

## TEMPLATE 2 — INSTAGRAM STORY / TIKTOK COVER (1080 × 1920 px)
*Use as video thumbnail or static story.*

### Layout structure
```
┌──────────────────────────────┐
│  [Logo + "Tchotcho Pay"]     │  ← top, 80px from edge
│                              │
│                              │
│   [BIG EMOJI / ICON]         │  ← center top, 200px
│                              │
│   [HEADLINE — 3 lines ok]    │  ← center, 80px font
│                              │
│   [1–2 lines body]           │  ← 42px font
│                              │
│   [CTA button]               │  ← rounded rect, cyan fill
│                              │
│   [tchotchopay.com]          │  ← bottom center
└──────────────────────────────┘
```

### Key differences from square template
- Font sizes are larger: headline 80–96px, body 42px
- Add a CTA button: rounded rectangle, fill `#00AEEF`, white Poppins Bold text, 48px — e.g. "Rejwenn Nou Gratis"
- Logo includes the full wordmark below the icon
- You have more vertical space — use it for a graphic (card mockup, phone mockup, or flag)

### Adding a phone/card mockup
- Go to Canva Elements → search "phone mockup" → pick a dark/minimal one
- Place it in the upper half, behind the text
- Colorize it: select image → Edit image → Duotone → set shadows to `#020B2D`, highlights to `#00AEEF`

## TEMPLATE 3 — FACEBOOK / OPEN GRAPH (1200 × 630 px)
*Also works as the Twitter/X card at 1600×900.*

### Layout structure (horizontal / split)
```
┌────────────────────┬─────────────────────┐
│                    │                     │
│  [HEADLINE]        │  [Graphic / Card]   │
│  [Body text]       │  [illustration]     │
│  [Stat pills]      │                     │
│  [CTA link]        │                     │
│                    │                     │
└────────────────────┴─────────────────────┘
     Left 55%              Right 45%
```

### Build notes
- Divide canvas with a vertical divider line `#00AEEF`, 2px wide, at x=660px
- Left side: all text content, left-aligned, 80px padding
- Right side: card mockup, phone mockup, or large icon (centered in panel)
- Background: full `#020B2D`
- Right panel background: `#0A1F6E` (slightly lighter) to create depth

## HOW TO BUILD ALL TEMPLATES IN ONE SESSION

1. Build Template 1 (1080×1080) first — get all colors, fonts, and layout right
2. Duplicate it → change to Template 2 size (resize canvas) → adjust layout for vertical
3. Duplicate again → Template 3 size → adjust for horizontal split
4. For each of the 5 topics, duplicate your base template and only change the "swap zone" elements
5. You'll end up with **15 designs** (3 sizes × 5 topics) ready to go
6. Export as PNG, 1x or 2x resolution
